# AI + 低代码平台

**利用智能体和领域模型，让懂业务的人把想法转变成企业级可直接上线运行的应用系统。**

## 平台技术栈

平台全栈使用 TypeScript：前端、服务端与边缘网关共用同一套设计结构定义，应用在设计、预览、上线三个阶段由同一套渲染器呈现，所见即所得。

| 层 | 技术 |
| --- | --- |
| 开发语言 | TypeScript（前端、服务端、边缘网关全栈统一） |
| 前端应用 | React 18 + Vite 6 + Ant Design 5（运行端、管理台两个应用） |
| 页面渲染 | 自研页面渲染器 + 共享组件库（设计预览与正式运行共用同一套渲染逻辑） |
| 流程设计 | React Flow（流程图节点编排） |
| 边缘网关 | Cloudflare Workers + Hono（请求转发、公开内容缓存、源站不可用时降级浏览） |
| 前端托管 | Cloudflare Pages；静态快照分发用 Cloudflare R2，降级缓存用 Cloudflare KV |
| 服务端 | Node.js + Hono（业务接口与智能体两个独立服务，Docker 容器运行） |
| 数据库 | PostgreSQL 18 + pgvector（业务数据与知识库向量检索同库）；Redis（运行时缓存） |
| 数据校验 | Zod（设计结构与接口入参的模式校验） |
| AI 接入 | OpenAI 兼容接口双通道（对话模型与向量模型分别配置，向量维度可配） |
| 移动端 | Capacitor 8（同一套 Web 应用打包为 Android / iOS App） |
| 工程与交付 | pnpm monorepo；GitHub Actions 构建 Docker 镜像并发布到 GHCR，服务器侧 Docker 编排部署 |

## 功能一览

| 功能 | 描述 |
| --- | --- |
| **领域模版** | 内置内容、商城、论坛、客服、协同办公等多套领域模版，数据表、页面、流程、权限成套生成，也可空白起步、自定义扩展 |
| **样板库** | 请假、报销、付款、入职等办公单据样板整套选用安装，字段、流程、页面一并到位 |
| **数据建模** | 表单式定义数据表与字段：文本、数字、日期、选项、附件、富文本、关联、主子表等，带校验规则、默认值与唯一约束 |
| **页面设计** | 列表页、表单页自动生成，也可自由拼装不绑定数据的自定义页面；菜单由页面驱动，同一页面可分别设计电脑版与手机版布局 |
| **流程设计** | 图形化拖拽审批流程，节点、审批角色、状态回写与驳回处理全部可视化配置 |
| **数据权限** | 按角色配置菜单可见与操作范围，细到行级数据范围（本人 / 本部门 / 全部）、字段只读与敏感字段脱敏，服务端统一执行 |
| **助手设计** | 为每个应用配置智能助手的形象、能力与知识来源，员工、访客、运营三种助手分别设置 |
| **AI 向导** | 对话式逐步生成应用：先数据模型，再页面、流程、权限，每一步确认后才落稿，成果与手工搭建完全一致、随时可改 |
| **AI 设计助手** | 搭建过程中随时让 AI 加字段、改页面、补流程，改动以提案形式呈现，确认后才生效 |
| **版本发布** | 草稿与线上版本分离管理，发布一键完成，出问题可回滚到任意历史版本 |
| **应用管理** | 创建、改名、启用与停用应用，设置占据首页的主应用，应用健康状态集中查看 |
| **权限管理** | 平台用户、角色、菜单权限统一维护，谁能进哪个应用、看哪些菜单由授权决定 |
| **角色管理** | 平台预置角色与自定义角色并存，角色的数据范围与操作权限成套配置 |
| **运营授权** | 把某个应用的日常运营授权给指定人员，对方登录后只能看到被授权的这一个应用 |
| **领域管理** | 每类应用有专属管理页：文章、订单、工单、会员等按业务对象管理，不用在通用表格里凑合 |
| **数据直改** | 运营中发现数据错误可在管理台直接修正，每一次修改都全程进入审计 |
| **主题模版** | 电脑版与手机版主题分别设置，可用领域提供的主题，也可上传应用专属主题，预览满意再启用 |
| **域名绑定** | 每个应用可绑定自己的域名，未绑定的走平台默认域名下的专属路径 |
| **系统配置** | AI 模型接入、支付参数、邮件发送等平台级设置在配置中心集中维护，不用改代码 |
| **审计日志** | 谁在何时改了什么全量留痕，可按应用、人员、记录检索并回放全过程 |
| **成本与熔断** | AI 调用按用途分开计量（搭建、助手、客服各一池），用量可查，超预算自动熔断 |
| **业务办理** | 按生成的列表与表单开单、查单、改单，支持多条件筛选、排序、分页、字段汇总与附件上传 |
| **待办中心** | 所有应用的待办汇聚一处：待我审批、我发起的、已处理、通知，含催办与流程时间线 |
| **审批处理** | 多级审批按角色自动派单，通过与驳回自动回写单据状态，全过程留痕 |
| **内容发布** | 栏目、文章与公开页面一站管理，发布后生成静态副本，访问更快 |
| **官网表单** | 官网的留言、报名等表单提交后自动进入后台，成为一条可跟进的业务数据 |
| **商城经营** | 商品、购物车、结算下单与订单处理齐全，收款由第三方支付完成，平台不经手资金 |
| **论坛社区** | 版块、发帖、回复与会员互动齐备，会员版主可置顶、加精、处理违规内容 |
| **在线客服** | 访客咨询先由 AI 按知识库应答，答不上来或访客要求时自动转工单，由客服接续处理 |
| **会员中心** | 会员注册登录带图形验证码防刷，账号与资料集中管理，会员可在手机与电脑上使用 |
| **会员域共享** | 官网、商城、论坛可以共用同一套会员，一次注册、处处登录 |
| **账户中心** | 会员身份集中在统一账户中心管理，各应用通过单点登录接入 |
| **会员角色** | 版主这类身份直接在会员体系内任命与收回，与员工账号完全分开 |
| **员工助手** | 在应用里用大白话查数据、做汇总、起草单据、发起流程；改数据前先出草稿，你确认才执行，能看的数据严格等于你本人的权限 |
| **访客助手** | 7×24 在线答客，答案只来自审核过的知识库，不引用未发布内容 |
| **运营助手** | 在管理台里对话式查询运营数据、待办与汇总，不用逐页翻找 |
| **知识库** | 产品手册、政策文档、常见问题按语义检索答题，内容先审后发，待审核资料绝不被提前引用 |
| **移动布局** | 页面有手机版布局时用手机版，没有时自动适配窄屏，手机浏览器直接可用 |
| **App 打包** | 同一套应用可打包成 Android 与 iOS 应用发布，支持扫码、拍照等手机能力 |
| **公开面防护** | 对外只展示已发布内容，未发布草稿即使知道地址也打不开 |
| **降级浏览** | 服务器短暂不可用时，已发布公开页面由边缘缓存副本继续提供浏览，恢复后自动回到实时数据 |
| **数据自有** | 全部业务数据保存在自有服务器的数据库中，云端只放展示副本，更换云账号不影响业务数据 |

## 部署方式

平台分两处部署协同工作：**前端应用与访问网关部署在 Cloudflare**，就近为各地用户提供访问；**业务服务与数据库部署在自有服务器**（Docker 方式运行），数据始终留在自己服务器上。访问入口按应用分配：主应用使用平台默认域名， 其他应用绑定自有域名或使用默认域名下的专属路径。提供两个使用入口：

| 入口 | 给谁用 | 做什么 |
| --- | --- | --- |
| 应用运行端 | 员工、会员、访客 | 办业务、走审批、逛官网/商城/论坛、咨询客服 |
| 管理台 | 管理员、运营人员 | 管应用、管数据、管人员、看审计与统计（设计器也集成在管理台内） |

## 本仓库包含什么

本仓库是平台部署在 Cloudflare 上的部分：前端应用与统一访问网关，与平台的服务器端仓库 `lcdp-platform` 配套发布。

| 目录 | 内容 |
| --- | --- |
| `apps/runtime` | 应用运行端：业务办理、待办中心、智能助手、客服浮窗 |
| `apps/admin` | 管理台：运营管理与集成的设计器 |
| `apps/studio` | 设计台：独立设计环境（已下线，设计器已并入管理台，代码保留） |
| `packages/renderer` | 页面渲染器：把设计好的页面结构渲染成真实界面，设计预览与正式运行共用同一套 |
| `packages/ui` | 共享界面组件库 |
| `src` | 统一访问网关：请求转发与源站不可用时的降级浏览 |

本地运行：

```bash
pnpm install
pnpm --filter @lcdp/runtime dev   # 本地起单个前端
pnpm dev                          # 本地起网关（wrangler dev）
```
